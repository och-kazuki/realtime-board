# ADR-012：付箋の位置と重なりの順番

- 状態：確定
- 決めた人：Claude の判断
- 記録した日：2026-11-27

## 状況

付箋をどこまで動かせるかと、付箋が重なったときにどれを上に表示するかを決める必要があった。

## 選択肢

- 位置：どこまでも広がるボードにする、または広さに限りのあるボードにする
- 重なり：作った順に重ねる、または最後に触った付箋を上にする

## 決定

- ボードの広さには限りがあり、付箋はボードの範囲の外には出せない
- 付箋が重なったときは、最後に追加・移動・編集した付箋を一番上に表示する

## 理由

- 広さに限りがあれば、付箋が遠くへ行って見つからなくなることがなく、位置が正しいかの確認も単純になるため
- 最後に触った付箋が上にあれば、いま作業している付箋がほかの付箋に隠れないため

## 受け入れたトレードオフ

- ボードがいっぱいになると、付箋を置く場所がなくなる
- 付箋を動かしたり編集したりするたびに、重なりの順番も変わる
