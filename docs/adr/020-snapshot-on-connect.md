# ADR-020：接続した直後に、WebSocket でボードの中身をまとめて送る

- 状態：確定
- 決めた人：Claude の提案をユーザーが承認
- 記録した日：2026-11-28

## 状況

ボードを開いた画面に、それまでに追加された付箋を表示する必要がある。付箋の一覧をどうやって画面に渡すかを決める必要があった。

## 選択肢

- REST の API で付箋の一覧を取ってから、WebSocket でつなぐ
- WebSocket でつないだ直後に、サーバーが付箋の一覧をまとめて送る（`snapshot`）

## 決定

- WebSocket でつないだ直後に、サーバーが付箋の一覧を `snapshot` として、接続した本人にだけ送る
- Hub は接続を登録するときに、その接続の送信待ちへ `snapshot` を入れる

## 理由

REST で取ってから WebSocket でつなぐと、取ってからつなぐまでの間にほかの人がした操作を取りこぼす。Hub が登録と同時に送信待ちへ `snapshot` を入れれば、そのあとの結果も同じ送信待ちに入るので、取りこぼしが起きない（ADR-019）。

## 受け入れたトレードオフ

- 付箋が多いほど、接続した直後に送るメッセージが大きくなる
- `snapshot` を取り直したいときは、いったん切ってつなぎ直す必要がある
