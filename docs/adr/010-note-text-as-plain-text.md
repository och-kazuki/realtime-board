# ADR-010：付箋の文字は文字として表示する

- 状態：確定
- 決めた人：Claude の判断
- 記録した日：2026-11-27

## 状況

付箋の文字には、利用者が入力したものがそのまま入る。それをどう表示するかを決める必要があった。

## 選択肢

- HTML や Markdown として表示する
- 文字として表示する

## 決定

付箋の文字は文字として表示し、HTML として解釈させない。改行は表示に反映する。

## 理由

入力された文字を HTML として解釈すると、ほかの人の画面で悪意のあるスクリプトが動く恐れ（XSS）があるため。付箋は短いメモなので、装飾がなくても困らない。

## 受け入れたトレードオフ

太字やリンクなどの装飾は使えない。
