# ADR-007：画面、サーバー、設計書を1つのリポジトリに置く

- 状態：確定
- 決めた人：Claude の判断
- 記録した日：2026-11-27

## 状況

画面、サーバー、設計書をどのリポジトリに置くかを決める必要があった。

## 選択肢

- 画面とサーバーでリポジトリを分ける
- 1つのリポジトリに置く

## 決定

画面のコードは `web/`、サーバーのコードは `server/`、設計書は `docs/` に置き、すべてを1つのリポジトリで管理する。

## 理由

画面とサーバーの両方に関わる変更（やり取りするデータの形を変えるなど）を、設計書と一緒に1つの PR でレビューできるため。

## 受け入れたトレードオフ

TypeScript と Go の2つの開発環境が1つのリポジトリに入るので、ビルドとテストの手順を言語ごとに用意する必要がある。
