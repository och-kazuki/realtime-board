# ADR-004：画面は TypeScript と React、サーバーは Go で作る

- 状態：確定
- 決めた人：ユーザーが決定
- 記録した日：2026-11-27

## 状況

学習の題材として作るアプリで、画面とサーバーの言語を決める必要があった。

## 選択肢

- Rust を新しく学ぶ
- これまで触れてきた TypeScript、Python、Java を掘り下げる
- TypeScript を主な言語にし、サーバー側の言語として Go を学ぶ

## 決定

画面は TypeScript と React、サーバーは Go で作る。

## 理由

ユーザーが TypeScript を主な言語として掘り下げ、サーバー側の言語として Go を自在に使えるようになることを目標にしたため。学習のロードマップも同じ組み合わせで進めている。

## 受け入れたトレードオフ

画面とサーバーで言語が分かれるので、やり取りするデータの形を TypeScript と Go の両方で同じに保つ必要がある。
