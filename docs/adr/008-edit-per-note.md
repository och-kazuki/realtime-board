# ADR-008：編集は付箋1枚を単位にする

- 状態：確定
- 決めた人：Claude の判断
- 記録した日：2026-11-27

## 状況

複数人が同じボードを編集するときに、どこまで同時の編集に対応するかを決める必要があった。

## 選択肢

- 1つの付箋の文字を、複数人で同時に1文字ずつ編集できるようにする（CRDT などを使う）
- 編集は付箋1枚を単位に扱う

## 決定

編集は付箋1枚を単位に扱う。1つの付箋の文字を複数人で同時に1文字ずつ編集する機能は作らない。

## 理由

1文字単位の同時編集には CRDT などの専門的な仕組みが必要で、学習の題材としては重すぎるため。このアプリでは Go の並行処理とリアルタイムの通信を学ぶことを優先する。

## 受け入れたトレードオフ

同じ付箋を複数人が同時に編集したとき、両方の編集を混ぜることはできない。
