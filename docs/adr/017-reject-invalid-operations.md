# ADR-017：サーバーは決まりに合わない操作を直さずに受け付けない

- 状態：確定
- 決めた人：Claude の提案をユーザーが承認
- 記録した日：2026-11-28

## 状況

M2 から、サーバーはブラウザから届いた操作を確かめる。付箋の状態の関数はボードの範囲の外の位置を範囲に収めて反映し、200字を超える文字への変更では何も変えない。サーバーに決まりに合わない値が届いたとき、直して受け付けるか、受け付けないかを決める必要があった。

## 選択肢

- 位置はボードの範囲に収め、文字は200字に切り詰めて受け付ける
- 決まりに合わない値を含む操作は直さずに受け付けない

## 決定

サーバーは決まりに合わない値を含む操作を直さずに受け付けない。付箋の位置が整数でないとき、ボードの範囲の外にあるとき、文字が200字を超えるときも同じに扱う。

## 理由

画面は位置をボードの範囲に収め、文字を200字までにしてから送る。そのため、決まりに合わない値が届くのは、画面の処理に誤りがあるときか、画面を通さずに送られたときだけになる。また、付箋の状態の関数が200字を超える文字への変更で何も変えないのと、サーバーの扱いがそろう。

## 受け入れたトレードオフ

画面とサーバーで位置の計算や文字の数え方が食い違うと、画面では正しく操作したのに、サーバーが受け付けない。画面とサーバーで同じ決まりを保つ必要がある（ADR-013、ADR-014）。
