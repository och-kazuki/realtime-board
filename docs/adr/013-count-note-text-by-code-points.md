# ADR-013：付箋の文字数は Unicode のコードポイントで数える

- 状態：確定
- 決めた人：Claude の提案をユーザーが承認
- 記録した日：2026-11-27

## 状況

ADR-011 で付箋の文字数の上限を200字と決めたが、何を1字と数えるかは決めていなかった。画面（TypeScript）とサーバー（Go）で数え方が違うと、画面では入力できた文字をサーバーが受け付けないことが起きる。

## 選択肢

- UTF-16 の単位で数える（JavaScript の `length` と、入力欄の `maxLength` の数え方）
- Unicode のコードポイントで数える
- 見た目の1文字（書記素クラスタ）で数える

## 決定

- 付箋の文字数は Unicode のコードポイントの数で数える。改行も1字と数える
- ADR-011 の200字はこの数え方で数える
- 上限を超える文字への変更は切り詰めずに受け付けない。画面の状態でもサーバーでも同じ扱いにする

## 理由

TypeScript では `Array.from(text).length`、Go では標準ライブラリの `utf8.RuneCountInString` で、同じ数を数えられるため。UTF-16 の単位は JavaScript の内部の表し方に合わせた数え方で、UTF-8 で文字列を持つ Go とは単位が違う。書記素クラスタは Go の標準ライブラリだけでは数えられない。

## 受け入れたトレードオフ

- 肌の色を変えた絵文字のように、見た目は1文字でも2字以上と数える文字がある
- 入力欄の `maxLength` は UTF-16 の単位で数えるので使えない。文字数の制限は画面で作る必要がある
