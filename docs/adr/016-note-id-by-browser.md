# ADR-016：付箋の `id` はブラウザが UUID で決める

- 状態：確定
- 決めた人：Claude の提案をユーザーが承認
- 記録した日：2026-11-27

## 状況

付箋を追加したら、すぐに文字を入力できるようにする（M1 の要件）。M2 でサーバーが付箋の `id` を決めると、画面は `id` が届くまで追加した付箋を見分けられない。そのため、編集を始める処理がサーバーの返事を待つ形に変わる。

## 選択肢

- サーバーが `id` を決め、追加の結果として返す
- ブラウザが UUID で `id` を決め、サーバーに送る

## 決定

- 付箋の `id` は、付箋を追加するときにブラウザが UUID で決める。M2 以降は決めた `id` をサーバーに送る
- UUID の作り方は限定しない

## 理由

追加した付箋をすぐ編集する流れを、M1 と M2 で変えずに済むため。また、付箋の状態を扱う関数の中で `id` を作らないので、その関数を入力だけで結果が決まる形に保てる。

## 受け入れたトレードオフ

- サーバーは、ブラウザから届いた `id` が UUID の形か、ほかの付箋の `id` と同じでないかを確かめる必要がある
- `crypto.randomUUID()` は HTTPS か localhost で開いたときにしか使えないので、HTTP で開くときは別の作り方が要る
