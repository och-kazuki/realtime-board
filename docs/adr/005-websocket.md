# ADR-005：リアルタイムの通信に WebSocket を使う

- 状態：確定
- 決めた人：ユーザーが決定
- 記録した日：2026-11-27

## 状況

ほかの人の操作をすぐに画面へ反映するために、ブラウザとサーバーの間でリアルタイムに通信する方法を決める必要があった。

## 選択肢

- Server-Sent Events（サーバーからの通知だけを受け取り、操作は HTTP で送る）
- WebSocket

## 決定

ブラウザとサーバーのリアルタイムの通信には WebSocket を使う。

## 理由

ユーザーがアプリの案の中から、WebSocket と、goroutine と channel による配信を学ぶ案（リアルタイム共有ボード）を選んだため。

## 受け入れたトレードオフ

接続が切れることがあるので、再接続の仕組みが必要になる。
