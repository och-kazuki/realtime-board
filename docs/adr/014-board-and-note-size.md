# ADR-014：ボードと付箋の大きさを固定し、位置を整数の px で表す

- 状態：確定
- 決めた人：Claude の提案をユーザーが承認
- 記録した日：2026-11-27

## 状況

ADR-012 でボードの広さに限りを設けると決めたが、具体的な大きさと、付箋の位置の表し方は決めていなかった。M2 ではサーバーも付箋の位置を確かめるので、画面とサーバーで同じ値を使う必要がある。

## 選択肢

- ボードの大きさ：画面の大きさに合わせて変える、または固定する
- 付箋の大きさ：文字の量に合わせて変える、または固定する
- 位置：小数を許す、または整数にする

## 決定

- ボードの大きさは横3000px、縦2000px、付箋の大きさは横200px、縦200pxで固定する
- 付箋の位置は、付箋の左上の角がボードの左上からどれだけ離れているかを、整数の px で表す
- `x` は 0 以上 2800 以下、`y` は 0 以上 1800 以下とする

## 理由

- 大きさが画面や文字の量で変わると、ボードの端で止める計算に画面の表示が要る。そうなると、付箋の状態を扱う処理を画面なしでテストできず、サーバーでも位置を確かめられない
- 整数にすると、見た目では同じ位置なのに、小数の差で別の位置と扱われることがない

## 受け入れたトレードオフ

- 大きな画面ではボードが画面より小さく表示される
- 付箋に入りきらない文字は付箋の中でスクロールして読む
- ボードや付箋の大きさを変えるときは、画面とサーバーの両方を直す
