# ADR-009：画面と付箋の状態の処理を、通信の処理から切り離す

- 状態：確定
- 決めた人：Claude の判断
- 記録した日：2026-11-27

## 状況

画面と付箋の状態を扱う処理と、通信の処理をどう組み合わせるかを決める必要があった。

## 選択肢

- 画面の部品の中で、直接サーバーと通信する
- 画面と付箋の状態を扱う処理を、通信の処理から切り離す

## 決定

画面と付箋の状態を扱う処理には通信の処理を入れず、通信の方法に依存させない。

## 理由

通信の方法を変えても、画面と付箋の状態を扱う処理を変えずに済むため。また、付箋の状態を扱う処理を、通信なしでテストできる。

## 受け入れたトレードオフ

画面と通信の間に層が1つ増えるので、コードの量と、読むときにたどる場所が増える。
