# 概要

## 何を作るか

複数人が同じボードに付箋を貼り、ほかの人の操作がすぐに自分の画面にも反映される Web アプリです。画面は TypeScript（React）、サーバーは Go で作ります。学習の題材として、Go の並行処理、同時に編集したときの扱い、リアルタイム通信を学ぶことを目的にしています。

最終的に作る機能は次のとおりです。

- 付箋の追加・移動・文字の編集・削除
- ほかの人の操作がすぐに自分の画面にも反映される
- いまボードを開いている人数の表示
- 複数のボードと、URL での共有
- ログインと、ボードのメンバー・権限

1つの付箋の文字を、複数人で同時に1文字ずつ編集する機能（共同エディタのような機能）は作りません。CRDT などの専門的な仕組みが必要になり、題材として重すぎるためです。編集は付箋1枚を単位に扱います（ADR-008）。

## 全体の構成

```
ブラウザ（React + TypeScript）
    │  WebSocket（操作と通知）
    ▼
Go サーバー
    │
    ▼
PostgreSQL（ボードと付箋を保存）
```

画面のコードは `web/`、サーバーのコードは `server/`、設計書は `docs/` に置きます。使う技術とリポジトリの構成を決めた理由は、ADR-004〜007 にあります（[ADR の一覧](adr/README.md)）。

## 作る段階

| 段階 | 作るもの | 始める時期 | 目安 |
|---|---|---|---|
| M1 1人用のボード | 画面だけで付箋を操作できるボード。サーバーは使わない | ロードマップの Phase 3 を終えたあと | 1〜2週 |
| M2 みんなで見えるボード | Go の WebSocket サーバーで、操作を全員に配る。ボードは1つで、データはメモリに持つ | Phase 4 を終えたあと（学習ガイド第35週の `net/http` の部分を先に読む） | 2週 |
| M3 消えないボード | 複数のボード、PostgreSQL への保存、同時に編集したときの扱い、再接続 | ロードマップを終えたあと | 3〜4週 |
| M4 公開 | ログインとメンバー、デプロイ、監視 | M3 のあと | 2〜3週 |

M1 と M2 はロードマップの途中に寄り道として作り、M3 と M4 はロードマップを終えてから作ります。
