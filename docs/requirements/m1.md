# M1 要件：1人用のボード

## 目的

サーバーを使わずに、画面だけで付箋を操作できるボードを作ります。ねらいは次の2つです。

- ロードマップの Phase 3 で学んだ React と TypeScript を、別の題材で使う
- M2 でサーバーとつなぐときにそのまま使える画面を、先に作っておく

## できること

1. ボードの画面を開くと、空のボードが表示される
2. 付箋を追加できる。新しい付箋は表示中の範囲に現れ、すぐに文字を入力できる
3. 付箋をドラッグして動かせる。付箋はボードの範囲の外には出せない（ADR-012）
4. 付箋の文字を編集できる。編集は確定も取り消しもできる
5. 付箋を削除できる。削除の前に確認はしない
6. 付箋が重なったときは、最後に追加・移動・編集した付箋が上に表示される（ADR-012）
7. ボードは画面より広く、スクロールして見渡せる

## 機能以外の要件

- 付箋の文字は文字として表示し、HTML として解釈させない。改行は表示に反映する（ADR-010）
- 付箋の文字数の上限は200字とし、上限を超える文字は入力できないようにする（ADR-011）
- M2 でサーバーとつなぐときに、画面と付箋の状態を扱う部分を変えずに、通信の部分だけを差し替えられる作りにする。どう作るかは設計で決める（ADR-009）
- 対応する環境はパソコンの最新の Chrome、Edge、Firefox とする

## 対象外

| 対象外のこと | 入れる段階 |
|---|---|
| ほかの人との共有、人数の表示 | M2 |
| 再読み込みしたあとも付箋が残ること | M3（DB に保存する） |
| 複数のボード、ボードの作成、URL での共有 | M3 |
| ログイン | M4 |
| 元に戻す、付箋の色と大きさの変更 | 未定 |
| スマートフォンとタブレットでの操作 | 未定 |

## 受け入れ条件

| ID | 条件 | 確かめ方 |
|---|---|---|
| M1-AC-01 | 付箋を追加すると、表示中の範囲に空の付箋が1枚増え、そのまま文字を入力できる | 自動テスト |
| M1-AC-02 | 付箋の位置を変える操作をすると、付箋がその位置に表示される | 自動テスト |
| M1-AC-03 | ボードの範囲の外へ動かす操作をしても、付箋はボードの端で止まる | 自動テスト |
| M1-AC-04 | 実際のブラウザで付箋をドラッグすると、手を離した位置に付箋が残る | 手動 |
| M1-AC-05 | 文字を編集して確定すると内容が変わり、取り消すと編集前の内容に戻る | 自動テスト |
| M1-AC-06 | 200字を超える文字は入力できない | 自動テスト |
| M1-AC-07 | 付箋を削除すると、その付箋だけが消える | 自動テスト |
| M1-AC-08 | 追加・移動・編集した付箋は、重なっているほかの付箋より上に表示される | 自動テスト |
| M1-AC-09 | `<b>太字</b>` や `<script>` を入力しても、入力した文字のまま表示される | 自動テスト |
| M1-AC-10 | 改行を含む文字は、改行したまま表示される | 自動テスト |
| M1-AC-11 | 画面と付箋の状態を扱う部分に、通信の処理が入っていない | 設計とコードのレビュー |

M1-AC-02 と M1-AC-03 は付箋の状態を扱う部分のテストで確かめます。テスト用の環境ではドラッグ操作を再現しにくいため、ドラッグそのものは M1-AC-04 として実際のブラウザで確かめます。

## レビューで決めたこと

| 決めたこと | 理由 |
|---|---|
| 再読み込みすると付箋は消えてよい | 保存は M3 で DB に入れるので、M1 ではブラウザに保存する仕組みを作らない |
| 付箋を削除する前に確認しない | 1人用なので消して困るのは自分だけで、M1 の範囲を小さく保てる |
| 付箋の文字数の上限は200字とする（ADR-011） | 付箋に書く短いメモには十分な長さ |
| スマートフォンとタブレットでの操作は対象外とする | 小さい画面での表示と操作まで確かめると、M1 の範囲が大きくなる |
